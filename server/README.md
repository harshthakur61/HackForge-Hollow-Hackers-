# Reserve Juggler: Node Replay Server & WebSocket Gateway

Node.js (TypeScript, port 4000) replay clock orchestrator and WebSocket streaming service.

## Local Development

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run with hot reloading:
   ```bash
   npm run dev
   ```

## Running Smoke Test

Run the 3-night automated replay smoke test:
```bash
npm run smoke
```
